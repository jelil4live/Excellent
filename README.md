the project title is secure storage bucket setup.
the problem context of this project is data privacy requires proper access control.
a storage container is configured in azure with least privilege access using share access signature(SAS).
share access signature SAS is URL that grants restricted access to an azure storage container.
this is mainly use when you want to grant access to storage account resources for a specific time range without sharing your storage account key.
